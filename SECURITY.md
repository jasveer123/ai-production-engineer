# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" button on the Security
tab of this repository. Please do not open a public issue. You will get an answer within 3 working
days. Never include real secrets or customer data in a report.

Scope: the API, web app, AI worker, sandbox worker, infrastructure code and the deployed
environment. Out of scope: findings that need physical access or a compromised developer machine.
